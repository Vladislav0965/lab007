# lab007
1. sum_digits(number) — сумма цифр
Что делает: берёт модуль числа (abs), затем в цикле while суммирует последнюю цифру (% 10) и отбрасывает её (//= 10).

Выполненные проверки:

Отрицательные числа — обрабатываются корректно благодаря abs(): например, sum_digits(-123) → 1+2+3 = 6.

Ноль — отдельная проверка if number == 0: return 0. Без неё цикл while number > 0 тоже вернул бы 0, так что проверка избыточна, но безопасна.

Положительные числа — стандартный случай.

Результат: функция корректно работает для любого целого числа, включая 0 и отрицательные.

2. average(numbers) — среднее арифметическое
Что делает: проверяет список на пустоту, иначе возвращает sum / len.

Выполненные проверки:

Пустой список — if not numbers: return None. Это защита от деления на ноль.

Непустой список — возвращается среднее.

Результат: для пустого списка возвращается None, в main.py это обрабатывается выводом "Нет данных". Для непустого — корректное среднее.

Замечание: в main.py список формируется как [float(x) for x in raw.split()]. Если пользователь введёт пустую строку, raw.split() даст [], и сработает ветка None — это корректно. Но если ввести нечисловые данные, будет ValueError — обработки ошибок нет.

3. normalize_text(text) — нормализация текста
Что делает: приводит к нижнему регистру (lower) и схлопывает все пробельные последовательности в один пробел (split() + " ".join).

Выполненные проверки:

Множественные пробелы/табы/переводы строк — split() без аргументов разбивает по любым пробельным символам и отбрасывает пустые строки, поэтому лишние пробелы устраняются.

Разный регистр — приводится к нижнему.

Ведущие и хвостовые пробелы — удаляются автоматически.

Результат: например, " Hello WORLD " → "hello world". Пустая строка → "".

4. select_numbers(numbers, porog) — индивидуальное задание
Что делает: возвращает числа из списка, удовлетворяющие условию -porog <= n <= 0.

Выполненные проверки:

Границы включительно — используются <= с обеих сторон, то есть -porog и 0 входят в выборку.

Отрицательные числа и ноль — отбираются; положительные — нет.

Порог — в main.py вводится как int, предполагается неотрицательным (по условию задания), но явной проверки на отрицательность порога нет.

Результат: например, при numbers = [-5, -3, 0, 2, -1] и porog = 3 → [-3, 0, -1]. Число -5 отброшено (меньше -3), 2 отброшено (больше 0).
